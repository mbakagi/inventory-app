📱 Install on Android (APK)

  1. Copy app-release.apk to your phone (USB, email, or cloud).
  2. On the phone, open the file. If warned, enable Install unknown apps for your file manager/browser.
  3. Tap Install and open ST3S Inventory.
  4. Grant Camera permission when asked (needed for barcode scan & OCR).
The APK works fully offline once the product catalog is loaded the first time.

🌐 Install as Web App (PWA)

  1. Open the app URL in Chrome (Android) or Safari (iOS).
  2. Android: menu ⋮ → Add to Home screen / Install app.
  3. iOS: Share → Add to Home Screen.
  4. Launch it from the home screen like a native app.

📷 Count Mode

  • Scan: tap Start Scanner and point the camera at a barcode/QR.
  • OCR: tap 📷 OCR to read a reference from a photo of a label.
  • Search: type a reference/name and tap a suggestion, or press Enter for an exact match.
  • Batch ⚡: keeps focus on the search box for fast repeated entry.
  • Undo ↩ reverses the last change. Save Session stores the count.

🔲 QR Codes & Labels

  • In the Catalog, tap 🔲 on a product to view & download its QR code.
  • Tap 🖨️ to print a single label, or use Print Labels for many.
  • Choose label size, columns and template (QR+Text / QR only / Text only), then Print to save a PDF.
  • Stick printed QR labels on shelves; scan them later in Count Mode.

💾 Backup & Restore

  • Backup downloads a JSON file with sessions, taxonomy & catalog.
  • Restore loads that file on any device to move your data.
  • Keep regular backups before clearing browser data or uninstalling.

🛠️ Troubleshooting

  • Scanner won't start: check camera permission & use HTTPS (or localhost).
  • QR not scanning: improve lighting; hold steady; clean the lens.
  • No products: use Sessions → Import Excel to load your Mg.xlsx.
  • Data lost: restore from your latest backup JSON.
